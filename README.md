# 🌱 AgriMind AI — Your Intelligent Farming Copilot

AgriMind AI is a multi-agent AI decision-support system that helps farmers make smarter, data-backed farming decisions. Instead of a single chatbot, specialized AI agents — Crop, Weather, Disease, and Market Intelligence — work together under a central orchestrator to analyze farm data and generate a personalized, actionable farming plan.

Built on **IBM Bob** (agent orchestration), **IBM Granite models** (reasoning & personalization), **IBM watsonx.ai** (deployment & governance), and a **RAG pipeline** grounded in agricultural knowledge, AgriMind AI turns raw farm inputs — crop, soil, location, symptoms — into a clear 7-day action plan, complete with reasoning and evidence.

## ✨ Key Features
- 🤖 Multi-agent architecture (Crop, Weather, Disease, Market agents)
- 📚 RAG-based agricultural knowledge retrieval for trustworthy recommendations
- 🌾 Personalized farming plans based on crop stage, soil, and location
- 🐛 AI-assisted disease/pest detection from symptoms or images
- 💧 Weather-aware irrigation guidance
- 💰 Market intelligence for harvest timing
- 🎛️ Visual AI Agent Network to show the system working in real time
- 🧪 Built-in Demo Mode for offline, reliable presentations

## 🛠️ Tech Stack
Next.js · React · TypeScript · Tailwind CSS · IBM Bob · IBM Granite · IBM watsonx.ai · RAG · Recharts · Framer Motion

## ⚠️ Disclaimer
AgriMind AI provides decision-support recommendations and is not a replacement for qualified agricultural professionals or local agricultural authorities.
